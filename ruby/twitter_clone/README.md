# Twitter Clone

This is a simple Twitter clone built with Ruby on Rails. The application allows users to sign up, log in, post tweets, follow other users, and view a timeline of tweets.

![](./tw_clone.png)

## Features

- User authentication (sign up, log in, log out)
- Post tweets (with character limit)
- Follow and unfollow users
- View your own timeline and public timelines
- Like and unlike tweets
- Responsive UI (if applicable)

## Getting Started

Follow these instructions to get the project up and running on your local machine.

### Prerequisites

- Ruby (version 3.0 or higher recommended)
- Rails (version 6 or higher)
- SQLite3 (for development)
- Node.js and Yarn (for Rails asset pipeline)

### Start the server

Start the server with:

```sh
./bin/dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
